# Library Assignment

## Getting Started

Follow the steps below to clone and run the project on your local machine.

You will need:
- Git
- Make
- A C++ compiler (`g++`)
- VS Code or another code editor

## Installing Git, Make, and a C++ Compiler

### On Linux (Ubuntu / Debian)

Open a terminal and run:
```bash
sudo apt update
sudo apt install git make build-essential
```

## Clone the Repository

1. Open **VS Code**
2. Create or open a folder where you want the project to live
3. Open the **Integrated Terminal**
4. Run the following command:

```bash
git clone git@github.com:K-Q-L-Y/library_assignment.git
```

### Running the Program
1. Run the following command:

```bash
make
./library
```
